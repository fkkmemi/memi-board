# AI 검사와 글쓰기 도우미 연결하기

지난 글에서는 다국어 화면과 콘텐츠 번역을 켰습니다. 이번에는 번역에도 필요한 **Firebase AI Logic을 연결하고, AI 콘텐츠 검사와 글쓰기 도우미**를 사용해보겠습니다.

메미보드의 AI 기능은 별도 서버 없이 브라우저에서 Firebase AI Logic(Gemini)을 호출합니다. 그래서 **아무나 AI를 호출하지 못하도록 App Check를 함께 설정**하는 것이 이번 편의 핵심입니다.

## AI로 할 수 있는 일

**콘텐츠 검사**: 글과 댓글을 저장하기 전에 금칙어와 AI로 검사합니다. 걸리면 저장되지 않습니다.

**글쓰기 도우미**: 맞춤법 검사, 문장 다듬기, 번역 미리보기

**AI 제목**: 제목을 비워 두면 본문으로 제목을 만들어 줍니다.

**콘텐츠 번역**: 지난 편에서 켠 번역 기능

## 1. AI Logic을 켭니다

Firebase 콘솔 → **AI Logic**에서 시작하고 **Gemini Developer API**를 선택합니다. 무료 요금제에서도 동작하지만 사용량 제한이 있어, 부족하면 종량제(Blaze)로 바꿉니다.

모델은 `nuxt.config.ts`에서 지정합니다.

```ts
memiBoard: {
  moderation: {
    enabled: true,
    model: 'gemini-3.5-flash-lite',
  },
},
```

예전 모델 이름(`gemini-2.5-flash`)은 새 프로젝트에서 404가 날 수 있으니 3.x 모델을 씁니다.

## 2. App Check를 설정합니다

App Check는 **내 사이트에서 온 요청만** AI를 쓰게 하는 장치입니다. 메미보드는 App Check를 직접 초기화하지 않으므로 내 사이트에서 설정합니다.

1. Google Cloud에서 **reCAPTCHA Enterprise 점수 기반 웹 키**를 만들고, 사이트 도메인을 등록합니다.
2. Firebase 콘솔 → App Check에서 그 사이트 키를 웹 앱에 등록합니다.
3. 브라우저 API 키의 허용 API에 **Firebase App Check API**를 추가합니다.

플러그인 코드는 길어서 AI에게 맡깁니다.

> memi-board README의 App Check 섹션 예제대로 `app/plugins/app-check.client.ts`를 만들어줘. 사이트 키는 `runtimeConfig.public.recaptchaSiteKey`에서 읽고, 로컬에서는 디버그 토큰을 쓰게 해줘.

사이트 키는 공개 값이라 설정에 넣어도 됩니다. **비밀 키는 절대 코드에 넣지 않습니다.**

로컬에서는 콘솔에 출력되는 디버그 토큰을 App Check → 디버그 토큰에 등록합니다. 운영 사이트에서는 디버그 토큰을 쓰지 않습니다.

## 3. AI Logic에만 적용을 켭니다

App Check가 잘 동작하는지 확인한 뒤, 콘솔에서 **AI Logic만 Enforce(적용)로 바꿉니다.**

Firestore와 Storage는 **모니터링 상태로 둡니다.** 이 둘까지 적용하면 글 저장과 이미지 업로드가 거부됩니다. 설치에서 자주 하는 실수입니다.

## 확인합니다

글을 하나 써서 저장해봅니다. 저장 전에 AI 검사가 진행되고, 문제가 없으면 글이 올라갑니다. 글쓰기 화면의 AI 버튼으로 맞춤법 검사도 해봅니다.

잘 안 될 때는 이렇게 확인합니다.

- App Check 토큰 오류: 사이트 키, 웹 앱 `appId`, 디버그 토큰 등록을 확인합니다.
- 모델 404: 모델 이름을 3.x로 바꿉니다.
- 글 저장 거부: Firestore나 Storage에 적용을 켜지 않았는지 확인합니다.

## 비용과 남용을 막는 장치

글쓰기 도우미는 사용자마다 **24시간에 10번**, AI 이미지는 **3장**까지 쓸 수 있습니다. 자동 번역은 이 횟수에 들어가지 않습니다.

검사에 여러 번 걸린 사용자는 경고가 쌓이고, 10번이 되면 하루 정도 글을 쓸 수 없습니다. 경고는 24시간마다 하나씩 줄어듭니다.

비용이 걱정되면 지난 편처럼 **사이트 전체 설정에서 AI 기능을 끄면** 됩니다. 금칙어 검사는 AI 없이 계속 동작합니다.
