# 메미보드를 설치하고 연결하기

지난 글에서는 개발 환경과 Firebase 프로젝트를 확인하고, 처음 만들 게시판을 정했습니다. 이번에는 **패키지를 설치하고 `nuxt.config.ts`에 메미보드와 Firebase 설정을 연결**하겠습니다.

**이번 강의도 AI와 대화하며 진행합니다.** 설정 파일을 직접 처음부터 쓰기보다, AI에게 설치 안내와 현재 프로젝트를 함께 읽게 한 뒤 필요한 부분을 합치도록 요청합니다. 결과는 직접 실행해서 확인합니다.

이번 편의 목표는 **사이트가 메미보드를 불러온 상태로 오류 없이 실행되는 것**입니다. 게시판 페이지를 만들고 보안 규칙을 배포하는 작업은 다음 편에서 진행합니다.

## AI에게 먼저 맡길 일을 정리합니다

AI 코딩 도구에서 프로젝트 폴더를 열고, 이렇게 요청해봅니다.

> 이 Nuxt 프로젝트에 memi-board를 붙이려고 해. https://github.com/fkkmemi/memi-board 의 README에서 Installation과 Host app setup의 1번, 4번을 읽고, 지금 프로젝트의 `package.json`, `nuxt.config.ts`, `app/assets/css/main.css`와 비교해서 바꿔야 할 부분을 먼저 정리해줘. 아직 파일은 수정하지 마.

바로 수정하게 하지 않고 **먼저 계획을 받는 것**이 요령입니다. 기존 사이트에는 이미 설정이 있기 때문에, AI가 무엇을 새로 추가하고 무엇을 바꾸려는지 확인한 뒤 진행하는 편이 안전합니다.

## 1. 패키지를 설치합니다

메미보드와 함께 Nuxt UI, Firebase 관련 패키지를 **호스트 앱에 직접** 설치합니다.

```bash
pnpm add memi-board @nuxt/ui nuxt-vuefire vuefire firebase
```

이미 설치된 패키지가 있다면 버전만 확인하면 됩니다. 에디터에서 쓰는 TipTap이나 날짜 처리 라이브러리는 따로 설치할 필요가 없습니다.

## 2. 모듈을 등록합니다

`nuxt.config.ts`의 `modules`에 세 모듈을 추가합니다. 메미보드는 Nuxt UI와 VueFire를 사용하므로 **`memi-board`를 뒤에 둡니다.**

```ts
export default defineNuxtConfig({
  modules: ['@nuxt/ui', 'nuxt-vuefire', 'memi-board'],
})
```

기존에 다른 모듈이 있다면 지우지 말고 함께 둡니다. memi.dev는 다국어 모듈을 쓰고 있어서 `['@nuxt/ui', '@nuxtjs/i18n', 'nuxt-vuefire', 'memi-board']` 순서로 되어 있습니다.

## 3. Firebase를 연결합니다

지난 편에서 준비한 **Firebase 웹 앱 설정 정보**를 `vuefire.config`에 넣습니다. Firebase 콘솔의 프로젝트 설정 → 내 앱 → 웹 앱의 SDK 설정에 나오는 값과 같아야 합니다.

```ts
vuefire: {
  config: {
    apiKey: '...',
    authDomain: '...',
    projectId: '...',
    storageBucket: '...',
    messagingSenderId: '...',
    appId: '...',
  },
  auth: { enabled: true },
},
```

웹 앱 설정 값은 브라우저에 공개되는 정보라 설정 파일에 들어가도 괜찮습니다. 하지만 **서비스 계정 키(Admin SDK용 JSON)는 절대 넣지 않습니다.** AI가 Admin SDK나 서버 API를 추가하자고 하면, 메미보드는 그것이 필요 없다고 알려주세요.

## 4. 메미보드 옵션을 설정합니다

처음에는 정한 대로 **한국어 하나, Google 로그인 하나**로 시작합니다.

```ts
memiBoard: {
  locale: 'ko',
  i18n: { enabled: false },
  auth: { providers: ['google'] },
  seo: {
    siteName: '내 사이트',
    siteUrl: 'https://example.com',
    basePath: '/board',
  },
},
```

**`locale`, `i18n`**: 화면 언어. 다국어를 끄면 한국어로 고정됩니다.

**`auth.providers`**: 로그인 버튼에 표시할 방식

**`seo.siteName`**: 링크 미리보기와 제목 뒤에 붙는 사이트 이름

**`seo.siteUrl`**: 실제 사이트 주소. 끝에 `/`를 붙이지 않습니다.

**`seo.basePath`**: 게시판 페이지 주소. 지난 편에서 정한 `/board`

AI 콘텐츠 검사와 번역은 나중에 필요할 때 켭니다. 별도의 `plugins/memi-board.ts` 파일은 만들지 않습니다. **모듈이 옵션을 알아서 전달하기 때문입니다.** AI가 플러그인 파일을 만들려고 하면 이 점을 짚어주세요.

## 5. 페이지별 렌더링 방식을 정합니다

게시글 목록과 본문은 **서버 렌더링(SSR)을 켠 상태로 둡니다.** 그래야 카카오톡이나 슬랙에 링크를 붙였을 때 제목과 이미지가 미리보기로 나옵니다.

글쓰기, 수정, 관리 화면은 로그인한 사용자만 쓰는 화면이라 브라우저에서만 그립니다.

```ts
routeRules: {
  '/board/**/new': { ssr: false },
  '/board/**/**/edit': { ssr: false },
  '/admin': { ssr: false },
  '/admin/**': { ssr: false },
},
```

예전 방식처럼 `/board/**` 전체를 `ssr: false`로 두면 링크 미리보기가 비게 됩니다. 이 부분은 AI가 자주 놓치는 곳이라 직접 확인해주세요.

## 6. CSS에 `@source`를 추가합니다

메미보드 컴포넌트는 `node_modules` 안에 있어서 Tailwind가 기본적으로 읽지 않습니다. 그대로 두면 **게시판이 스타일 없이 깨져 보입니다.** 메인 CSS 파일에 한 줄을 추가합니다.

```css
/* app/assets/css/main.css */
@import "tailwindcss";
@import "@nuxt/ui";
@source "../../../node_modules/memi-board/dist/runtime/components";
```

## 실행해서 확인합니다

설정을 마쳤으면 개발 서버를 실행합니다.

```bash
pnpm dev
```

이번 편에서 확인할 것은 세 가지입니다.

- 터미널에 **모듈을 찾지 못한다거나 설정 오류가 나는 메시지가 없는지**
- 기존 페이지가 **이전과 똑같이** 열리는지
- 브라우저 개발자 도구 콘솔에 Firebase 초기화 오류가 없는지

오류가 나면 메시지를 그대로 AI에게 붙여 넣고, 방금 바꾼 파일과 함께 원인을 찾아달라고 요청합니다.

> `pnpm dev` 실행하니까 아래 오류가 나와. 이번에 바꾼 `nuxt.config.ts`와 `package.json` 기준으로 원인을 찾고, 고치기 전에 무엇을 바꿀지 먼저 설명해줘.

이 시점에는 게시판 페이지가 아직 없으므로 `/board`로 들어가도 아무것도 나오지 않는 것이 정상입니다.
