# 강의 글 작성 지침

- 강의 글을 작성하거나 내용을 수정할 때는 글 하단에 실제 작성에 사용한 모델명과 추론 수준을 표시한다.
- 현재 세션의 실행 메타데이터에서 모델명과 추론 수준을 확인한다. 이전 글의 표기를 복사하거나 모델명을 추측하지 않는다.
- 표기 형식: `Written by {모델명} · Reasoning: {추론 수준}`
- 예: `Written by GPT-6.1 Sol · Reasoning: Medium`
- 확인할 수 없는 정보는 임의로 채우지 말고 확인 불가임을 명시한다.
- 이 지침 파일 자체는 강의 글이 아니므로 작성자 표기를 붙이지 않는다.
