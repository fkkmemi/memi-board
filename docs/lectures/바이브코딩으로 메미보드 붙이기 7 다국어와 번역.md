# 다국어 화면과 콘텐츠 번역 켜기

지난 글에서는 보드 설정을 다듬고 역할을 나눴습니다. 이번에는 처음에 꺼 두었던 **다국어 기능**을 켜보겠습니다.

메미보드의 다국어는 두 가지로 나뉩니다.

**화면 언어**: 저장, 취소 같은 버튼과 안내 문구, 날짜 표시

**콘텐츠 번역**: 보드 이름과 설명, 글의 제목·요약·본문을 다른 언어로 번역

화면 언어만 바꾸는 데는 AI가 필요 없습니다. 콘텐츠 번역은 **Firebase AI Logic**을 사용합니다. 지원하는 언어는 한국어, 영어, 일본어, 독일어, 프랑스어, 스페인어, 포르투갈어, 중국어, 아랍어, 인도네시아어 10가지입니다.

## 어떤 방식으로 쓸지 정합니다

`nuxt.config.ts`의 두 옵션 조합으로 정합니다.

**한국어만**: `i18n: { enabled: false }` (지금까지의 설정)

**화면만 다국어**: `i18n: { enabled: true }, translation: { enabled: false }`. 글은 쓴 언어 그대로 보입니다.

**화면과 글 모두 다국어**: `i18n: { enabled: true }, translation: { enabled: true }`

국내 사용자만 있다면 한국어만으로 충분합니다. 해외 방문자가 있다면 화면만 다국어로 시작하고, 필요할 때 번역을 켜는 순서가 부담이 적습니다.

## 사이트의 언어 전환과 연결합니다

사이트에 이미 언어 선택 기능이 있다면, 메미보드도 그 언어를 따라가게 할 수 있습니다. 보통 `@nuxtjs/i18n`을 사용합니다.

> memi-board의 `docs/internationalization.md` 3번을 읽고, 이 사이트의 `@nuxtjs/i18n` 언어 전환을 메미보드와 연결해줘. 우선 한국어와 영어만 쓰고, `memiBoard`는 화면만 다국어로 설정해줘.

AI가 하는 일은 대략 다음과 같습니다.

- `modules`에 `@nuxtjs/i18n` 추가와 언어 목록 설정
- `memiBoard.i18n.enabled`를 `true`로 변경
- `app.vue`에서 Nuxt UI의 언어와 `<html lang>`을 현재 언어에 맞추기

메미보드의 번역 파일은 패키지에 들어 있으므로 **복사하지 않습니다.** 사이트의 메뉴 문구 같은 것만 사이트의 번역 파일에 넣으면 됩니다.

언어를 바꿨을 때 보드의 버튼과 날짜가 함께 바뀌면 연결된 것입니다. 보드 설정의 **보드 언어**가 자동으로 되어 있어야 사이트 언어를 따라갑니다. 특정 언어를 고르면 그 보드는 항상 그 언어로 보입니다.

## 콘텐츠 번역을 켭니다

글까지 번역하려면 `translation.enabled`를 `true`로 바꿉니다. 그리고 Firebase 콘솔에서 **AI Logic을 연결**해야 합니다. 이 연결은 AI 검사 기능과 함께 쓰므로 다음 편에서 자세히 다룹니다.

연결이 끝나면 보드 설정에서 번역을 사용합니다.

**보드 이름과 설명**: 번역 버튼을 누르고 저장합니다.

**새 글 자동 번역**: 보드 설정의 **글·댓글 작성 시 자동 번역**을 켭니다. 기본값은 꺼짐입니다.

**기존 글 번역**: 번역이 없거나 원문이 바뀐 글을 찾아 한꺼번에 번역합니다.

번역은 원문 언어를 알아서 판별합니다. 영어 화면에서 한국어 글을 써도 원문은 한국어로 저장되고, 나머지 9개 언어로 번역됩니다.

## 끄고 싶을 때

비용 때문에 번역을 멈추고 싶다면 다시 배포하지 않아도 됩니다. 보드 설정 위쪽의 **사이트 전체 설정**에서 국제화나 AI 기능을 끄면 바로 반영됩니다.

꺼도 이미 저장된 번역은 지워지지 않습니다. 다시 켜면 원문이 바뀌지 않은 글은 저장된 번역을 그대로 씁니다.
