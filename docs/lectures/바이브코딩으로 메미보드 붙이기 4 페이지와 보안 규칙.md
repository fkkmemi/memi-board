# 게시판 페이지를 만들고 보안 규칙을 배포하기

지난 글에서는 패키지를 설치하고 `nuxt.config.ts`에 메미보드와 Firebase를 연결했습니다. 이번에는 **게시판 페이지를 만들고, Firebase 보안 규칙과 인덱스를 배포**하겠습니다.

메미보드는 페이지 주소를 직접 만들지 않습니다. **주소와 페이지 파일은 내 사이트가 만들고**, 그 안에 메미보드 컴포넌트를 놓는 방식입니다.

## AI에게 페이지 구성을 요청합니다

이번에도 바로 수정하지 않고 계획부터 받습니다.

> memi-board의 `docs/host-integration.md`에서 목록·글쓰기·상세 페이지 예제를 읽고, 이 프로젝트에 `/board/[category]` 목록, `/board/[category]/new` 글쓰기, `/board/[category]/[id]` 상세 페이지를 만들 계획을 정리해줘. 기존 레이아웃과 메뉴는 유지해줘.

계획이 괜찮으면 적용을 요청합니다. 만들어질 페이지는 세 가지입니다.

**목록**: `pages/board/[category]/index.vue`

**글쓰기**: `pages/board/[category]/new.vue`

**상세**: `pages/board/[category]/[id]/index.vue`

여기서 `[category]`가 게시판 ID입니다. 예를 들어 자유게시판을 `free`로 만들면 주소는 `/board/free`가 됩니다.

## 목록과 글쓰기는 컴포넌트 하나면 됩니다

목록 페이지는 `MemiBoardList`를 놓고, 글을 눌렀을 때 갈 주소를 알려줍니다.

```vue
<script setup lang="ts">
const route = useRoute()
const boardId = computed(() => String(route.params.category))
await useMemiBoardListSeo({ category: boardId, path: computed(() => `/board/${boardId.value}`) })
</script>

<template>
  <MemiBoardList
    :board-id="boardId"
    :get-post-link="post => `/board/${boardId}/${encodeURIComponent(post.slug)}`"
  />
</template>
```

`useMemiBoardListSeo` 한 줄이 링크 미리보기 정보를 채웁니다. 별도의 서버 API는 만들지 않습니다.

글쓰기 페이지는 `MemiBoardEditor`를 놓고, 저장되면 새 글로 이동합니다. `boardId`는 목록과 같은 방법으로 구합니다.

```vue
<template>
  <MemiBoardEditor
    :board-id="boardId"
    @saved="slug => navigateTo(`/board/${boardId}/${encodeURIComponent(slug)}`)"
  />
</template>
```

상세 페이지는 주소의 글 이름(slug)을 문서 ID로 바꾸는 과정이 있어 조금 더 깁니다. 이 부분은 설치 안내의 예제를 그대로 따르도록 AI에게 맡기는 편이 정확합니다.

컴포넌트는 모듈이 자동으로 불러오므로 `import`하지 않습니다. AI가 `memi-board/runtime`에서 컴포넌트를 가져오려고 하면 동작하지 않는다고 알려주세요.

## 보안 규칙과 인덱스를 합칩니다

화면이 있어도 **Firebase 보안 규칙이 배포되지 않으면 글이 저장되지 않습니다.** 설치에서 가장 많이 놓치는 단계입니다.

> memi-board의 docs에 있는 firestore.rules.example, storage.rules.example, firestore.indexes.json.example을 이 프로젝트의 규칙 파일에 합쳐줘. 기존 규칙은 지우지 말고, 바뀌는 부분을 먼저 보여줘.

기존 사이트에 규칙이 있다면 **덮어쓰지 않고 합치는 것**이 중요합니다. AI가 보여준 변경 내용에서 기존 규칙이 사라지지 않았는지 확인합니다.

`firebase.json`의 Storage 버킷이 `vuefire.config.storageBucket`과 같은지도 확인합니다. 다르면 이미지 업로드가 `storage/unauthorized`로 실패합니다.

## 배포합니다

규칙과 인덱스는 사이트를 배포한다고 함께 올라가지 않습니다. 직접 배포합니다.

```bash
firebase deploy --only firestore:rules,storage,firestore:indexes
```

배포 중 Storage가 Firestore를 읽도록 권한을 추가할지 물으면 승인합니다.

마지막으로 **새 프로젝트라면 한 번만** Firebase 콘솔의 Firestore에서 `memiBoardPostsSlugs` 컬렉션에 `__migration` 문서를 만들고, 불린 필드 `ready`를 `true`로 넣습니다. 글 주소를 예약하는 기능을 켜는 표시입니다.

## 확인합니다

`pnpm dev`로 실행하고 `/board/free`에 들어가봅니다. 아직 게시판 설정이 없으므로 빈 화면이나 안내 문구가 나오는 것이 정상입니다. 콘솔에 `permission-denied`가 보이면 규칙이 배포되지 않은 것입니다.
