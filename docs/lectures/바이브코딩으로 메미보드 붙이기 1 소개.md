# 메미보드를 소개합니다

메미보드는 **Nuxt와 Firebase로 만든 웹사이트에 게시판을 붙일 수 있는 패키지**입니다.

**이 강의는 AI와 대화하며 코드를 작성하고 수정하는 바이브코딩 방식으로 진행합니다.** 만들고 싶은 기능과 필요한 설정을 AI에게 설명하고, 생성된 코드를 실제 사이트에 적용해 동작을 확인합니다. 오류가 생기면 원인을 함께 살펴보며 해결하는 과정까지 다룰 예정입니다.

사이트를 만들 때마다 글쓰기, 댓글, 파일 첨부, 사용자 권한 같은 기능을 처음부터 구현하는 일이 반복됩니다. 이런 기능을 여러 사이트에서 재사용하고, 개선 사항도 함께 적용할 수 있도록 메미보드를 만들었습니다.

## 어떤 기능이 있나요?

게시글 작성·수정·삭제를 기본으로 다음 기능을 제공합니다.

- 댓글과 이미지·파일 첨부
- 게시판과 카테고리 구분
- 작성자·관리자 권한 관리
- 링크 공유 시 제목·설명·이미지 미리보기
- 선택적으로 사용하는 다국어 UI·콘텐츠 번역과 AI 콘텐츠 검사

## 어떻게 사용하나요?

**Nuxt 4, Nuxt UI, Firebase를 사용하는 프로젝트에 설치해서 연결합니다.**

메미보드가 게시판 기능을 제공하고, 적용할 사이트에서는 Firebase 연결과 페이지 경로, 레이아웃 등을 설정합니다. 각 사이트의 Firebase 프로젝트를 사용하거나, 하나의 프로젝트 안에서 게시판을 구분해 운영할 수 있습니다.

기본 게시판 기능은 별도 백엔드 서버나 Firebase Admin 없이 동작하며, 데이터 접근 권한은 Firebase 보안 규칙으로 관리합니다.
